# Fundamentos de Python - Clases y Objetos

## Descripción

Este repositorio contiene el desarrollo del taller de clases y objetos en Python.  
En este ejercicio se creó una clase llamada `Libro`, la cual permite representar un libro dentro de una biblioteca.

## Taller: Clases y Objetos

Se implementó una clase `Libro` con los siguientes atributos:

- titulo
- autor
- paginas
- disponible

También se crearon los siguientes métodos:

- `prestar()`: cambia el estado del libro a prestado.
- `devolver()`: cambia el estado del libro a disponible.
- `informacion()`: muestra toda la información del libro.
